노트북에 설치해서 **인터넷 없이** 쓰는 Read Classic 입니다. 사진·PDF 악보 인식, 연주 따라가기, 남은 시간 표시가 모두 노트북 안에서 됩니다.

## Windows
1. 아래 **ReadClassic-Windows-Setup.exe** 를 받아 실행합니다.
2. "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행** 을 누릅니다.
3. **설치** 를 누르면 끝. 바탕화면의 **Read Classic** 아이콘을 누르면 브라우저에 앱이 열립니다.

## Mac (M1 이후)
1. 아래 **ReadClassic-Mac.dmg** 를 받아 엽니다.
2. **Read Classic** 아이콘을 옆의 **Applications** 폴더로 끌어다 놓습니다.
3. 응용 프로그램 폴더에서 Read Classic 을 엽니다. 처음에 열리지 않으면 **시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기]** 를 누르고 다시 엽니다.

## 업데이트
- 다음 판부터는 다시 받을 필요 없이 **앱 안에서 업데이트**됩니다. 새 버전이 나오면 왼쪽 목록 맨 위에 **새 버전이 나왔어요** 카드가 뜨고, **지금 업데이트**를 누르면 1~2분 뒤 새 버전으로 다시 열립니다. 저장한 악보는 그대로 남습니다.
- 업데이트 기능이 없는 예전 판을 쓰고 있다면 이번 한 번만 위 방법으로 다시 설치하세요 (덮어써도 저장한 악보는 그대로입니다).

## 쓰는 법
- 아이콘을 누르면 브라우저(Chrome·Edge·Safari)에 앱이 열립니다. 창은 따로 뜨지 않고 뒤에서 돕니다.
- 끄기: 앱 오른쪽 위 **설정 → 앱 끄기** (컴퓨터를 끄면 같이 꺼집니다).
- 인식한 악보는 그 노트북의 브라우저에 저장됩니다.

Linux 는 **ReadClassic-Linux.zip** 을 풀고 `./read-classic` 을 실행하세요.
