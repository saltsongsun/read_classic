# basic-pitch.onnx

Spotify basic-pitch (ICASSP 2022) note/onset model, taken unchanged from the `basic-pitch` 0.4.0 Python package
(`basic_pitch/saved_models/icassp_2022/nmp.onnx`). Licensed under the Apache License 2.0 —
https://github.com/spotify/basic-pitch. Used for the AI note recognition in Read Classic.
