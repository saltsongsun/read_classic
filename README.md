# Read Classic · 악보 따라가기

마이크로 연주를 들으면서, 저장해 둔 악보에서 **지금 연주하고 있는 곳**을 실시간으로 표시해 주는 웹 앱입니다.
악보를 넘기거나 어디까지 쳤는지 찾을 필요 없이, 연주하는 음에 커서가 따라오고 화면이 알아서 스크롤됩니다.

- 🎤 **마이크 입력만으로 위치 추적**: 피아노처럼 여러 음을 함께 치는 악기도, 바이올린·플루트·노래처럼 한 음씩 내는 악기도 됩니다.
- 🎼 **악보 보관함**: MusicXML(`.musicxml`, `.xml`, 압축된 `.mxl`) 파일을 올리면 브라우저에 저장되어 다음에도 바로 열립니다.
- 🐢 **연습하는 그대로**: 느리게 치거나, 멈췄다 다시 치거나, 몇 마디 앞으로 돌아가 다시 치거나, 틀린 음을 쳐도 따라옵니다.
- 👆 **원하는 곳부터**: 악보의 음을 누르면 그 위치부터 따라갑니다.
- 🔒 **모든 처리는 브라우저 안에서**: 소리는 어디에도 전송되거나 저장되지 않습니다.

## 사용법

1. 왼쪽 목록에서 악보를 고르거나 **악보 파일 추가**로 MusicXML 파일을 올립니다.
   (MuseScore, Sibelius, Finale, Dorico 등에서 *내보내기 → MusicXML* 로 만들 수 있고, IMSLP·MuseScore 커뮤니티에도 MusicXML 악보가 많습니다.)
2. 아래의 **듣기 시작**을 누르고 마이크 권한을 허용합니다.
3. 첫 음부터 연주하면 빨간 커서(지금 음)와 노란 영역(지금 마디)이 따라옵니다.

| 조작 | 동작 |
| --- | --- |
| 악보의 음 누르기 | 그 음부터 따라가기 |
| `Space` | 듣기 / 멈춤 |
| `←` `→` | 한 음씩 이동 |
| `Home` | 처음으로 |
| `−` `+` (위쪽) | 악보 축소 / 확대 |

**설정**(위쪽 오른쪽 아이콘)

- *마이크 감도*: 주변이 시끄러우면 낮추고, 작게 연주하면 높이세요. 아래쪽 막대가 초록색이면 연주 소리로 인식하고 있는 것입니다.
- *연습 템포*: 악보에 적힌 템포가 기본값이며, 연주하는 동안 자동으로 맞춰집니다. 아주 느리게 연습할 때 미리 낮춰 두면 첫 몇 마디부터 더 정확합니다.
- *음정 판정*: 커서가 너무 쉽게 넘어가면 *엄격하게*, 잘 안 넘어가면 *너그럽게*.

> 마이크는 보안상 **HTTPS** 또는 `localhost` 에서만 켜집니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 사이트 생성 (어느 정적 호스팅에나 올릴 수 있음)
```

`main` 브랜치에 올리면 `.github/workflows/pages.yml` 이 GitHub Pages 로 배포합니다.
(처음 한 번 저장소 *Settings → Pages → Source* 를 **GitHub Actions** 로 바꿔 주세요.)

## 동작 원리

```
마이크 ─▶ AudioWorklet ─▶ 특징 추출 ──────────────▶ 악보 추적기(HMM) ─▶ 커서/스크롤
                          · 크로마(12음 이름별 세기)     · 악보 이벤트마다 어택/지속 상태
                          · 온셋(새 음이 시작됐는지)      · 머문 시간 ÷ 예상 길이로 다음 음 확률
                          · 레벨·스펙트럼 평탄도(잡음)    · 최근 2초 재탐색(되돌아가기·건너뛰기)
```

1. **악보 → 이벤트** (`src/score/view.ts`, `src/follow/build.ts`):
   OpenSheetMusicDisplay 로 악보를 그린 뒤 커서를 끝까지 움직이며 “새 음이 시작되는 지점”을 모읍니다.
   붙임줄로 이어지는 음과 쉼표는 건너뛰고, 이전부터 울리고 있는 음(긴 베이스음 등)도 함께 기록합니다.
   도돌이표는 OSMD 가 펼쳐 준 연주 순서를 그대로 따릅니다.
2. **소리 → 특징** (`src/audio/features.ts`):
   약 85ms 창의 FFT 에서 스펙트럼 봉우리를 찾아 정확한 주파수를 보간하고 12개 음 이름(크로마)으로 모읍니다.
   짧은 창의 스펙트럴 플럭스로 새 음의 시작(온셋)을 찾고, 레벨과 스펙트럼 평탄도로 연주 소리와 잡음을 구분합니다.
3. **추적** (`src/follow/tracker.ts`):
   각 이벤트는 *어택*(음이 막 시작됨)과 *지속* 두 상태를 갖는 은닉 마르코프 모델입니다.
   - 관측: 마이크 크로마와 이벤트의 배음 템플릿 사이의 코사인 유사도, 그리고 온셋 강도.
     같은 음을 다시 칠 때는 온셋이 있어야 넘어가므로 “미 미 파 솔”처럼 반복음도 하나씩 셉니다.
   - 전이: 지속 상태에 머문 시간이 예상 길이(템포 × 박자)에 가까워질수록 다음 음으로 넘어갈 확률이 커집니다.
     늘임표처럼 아주 오래 끌면 다시 낮아져서 기다려 줍니다. 템포는 실제로 넘어간 간격으로 계속 보정합니다.
   - 틀린 음: 유사도에 하한을 두어, 어디에도 맞지 않는 음이 커서를 엉뚱한 곳으로 끌고 가지 못하게 합니다.
   - 재탐색: 최근 2초 연주를 “현재 위치 근처 아무 데서나 시작”하는 모델로 다시 풀어 보고,
     지금 경로보다 확실히(로그우도 6 이상) 더 잘 설명할 때만 그 위치로 옮깁니다. 연주자가 앞 구절로 돌아가 다시 치는 경우를 잡아냅니다.

### 정확도

합성한 피아노·현악기 연주로 측정한 값입니다 (`npm run report`). *±1음*은 소리가 나는 동안 커서가 실제 연주 위치에서 한 음 이내에 있던 시간 비율입니다.

| 상황 | ±1음 | 정확히 일치 |
| --- | --- | --- |
| 피아노, 악보 템포 / 0.55배 / 1.35배 (환희의 송가) | 100% / 100% / 100% | 96% / 97% / 95% |
| 현악기 레가토, 0.55~1.35배 (작은 별, 반복음) | 100% | 78~90% |
| 피아노 화음·지속음 (바흐 전주곡 C장조, 304개 지점) | 99.8~100% | 77~91% |
| 3초 멈췄다 다시 | 100% | 93% |
| 틀린 음 10% 섞어 치기 | 98.6% | 90% |
| 10마디까지 치다가 9마디로 돌아가기 | 95.8% | 92% |
| 시끄러운 방 (강한 백색 잡음을 섞음) | 99.7% | 87% |

“정확히 일치”가 100% 가 아닌 것은 대부분 새 음이 시작된 뒤 커서가 따라오기까지의 지연(피아노 약 40ms, 현악기 약 100ms) 때문입니다.
실제 브라우저에서 같은 합성 연주를 가짜 마이크로 넣는 종단 테스트(`npm run e2e`)도 두 곡 모두 ±1음 100% 로 끝까지 따라갑니다.

### 한계

- PDF·사진 악보는 읽지 못합니다. MusicXML 이 필요합니다.
- 크로마(음 이름) 기반이라 옥타브만 다르게 친 것은 구분하지 못합니다.
- 똑같은 선율이 반복되는 곡에서 처음부터 다시 치면, 두 구간이 갈라지는 곳까지는 다른 반복 구간에 붙어 있을 수 있습니다. 갈라지는 순간 제자리로 돌아옵니다. 바로잡고 싶으면 악보를 눌러 위치를 지정하세요.
- 여러 악기가 함께 연주하는 합주는 고려하지 않았습니다.

## 개발

```bash
npm test           # 단위 테스트 + 합성 연주 추적 테스트 (약 40초)
npm run typecheck
npm run report     # 상황별 정확도 표 출력
npm run e2e        # Chromium 가짜 마이크로 실제 앱 종단 테스트 (Playwright 필요)
npm run samples    # samples/scores.mjs 로 예제 MusicXML 다시 만들기
```

```
src/
  audio/fft.ts         FFT
  audio/features.ts    크로마·온셋·잡음 판별, 소리 감지 게이트
  audio/mic.ts         마이크 입력 (AudioWorklet)
  follow/build.ts      악보 음 → 추적 이벤트
  follow/tracker.ts    악보 추적기 (HMM + 재탐색)
  score/view.ts        OSMD 렌더링, 커서 이동, 클릭 위치
  score/library.ts     IndexedDB 악보 보관함
  main.ts              화면 연결
samples/scores.mjs     예제 악보 정의 (환희의 송가, 작은 별, 바흐 전주곡 C장조 1–19마디)
tests/                 합성기, 시나리오, 테스트
```

예제 악보는 모두 저작권이 만료된 곡을 직접 입력한 것입니다.
